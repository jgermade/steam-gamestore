# Project bootstrap: working agreement and GOG installer design doc

- **Status:** completed
- **Started:** 2026-09-16
- **Roadmap:** not applicable (no roadmap revision drafted yet)

## 2026-09-16 — Initial setup

Added `docs/gog-installer.md`: the design document for the GOG installer that
surfaces installed GOG games as regular Steam tiles in Big Picture. It covers the
context, the decisions already made (Rust, Steam-managed Proton, Ludusavi for
saves, GitHub release binaries with a one-line installer), the proposed Rust
workspace split (`core` / `platform-linux` / `platform-windows`), the
restore/backup feedback approach, savegame sync options, and the open questions.

Added `AGENTS.md`, the working agreement for contributors:

- The roadmap lives in `ROADMAP/YYYY-MM-DD/` as Markdown files, and each revision
  carries a Gantt chart written with Mermaid.
- Every change is recorded in `RECORD/YYYY-MM-DD.<summary>.(WIP|completed).md`,
  and those files are append-only — the only permitted edit is renaming `.WIP.md`
  to `.completed.md` once the work is done.
- All of these files are written in English.

No roadmap revision has been created yet; the first one should turn the "Still to
define / next steps" section of `docs/gog-installer.md` into dated tasks.
