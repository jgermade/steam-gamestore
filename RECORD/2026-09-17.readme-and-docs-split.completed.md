# A shorter README, with the detail moved to docs/

- **Status:** completed
- **Started:** 2026-09-17

## 2026-09-17 20:35 — Why

The README had grown to 228 lines and ten sections, and was carrying four different
readerships at once: someone deciding whether this project is for them, someone
installing it, someone logging in to GOG, and someone building it. Whichever one you
were, most of the page was not for you — and the page was the first thing anyone saw.

`AGENTS.md` already says what `docs/` is for ("design documents and technical
notes"), and the only thing in it was the original design note.

## 2026-09-17 20:35 — What moved

| Was a README section | Is now |
|----------------------|--------|
| Install | [`docs/install.md`](../docs/install.md), plus the update rules, which are new |
| Logging in to GOG, Where the session is kept | [`docs/gog-login.md`](../docs/gog-login.md) |
| Trying it from Steam | [`docs/steam-tile.md`](../docs/steam-tile.md) |
| Build and run, Workspace, Releases | [`docs/development.md`](../docs/development.md) |

The prose was moved as it was written rather than rewritten, so nothing was lost in
the move and the diff is readable as a move. What is new: the update table in
`install.md`, the "what it touches" section that answers what is and is not
idempotent about an install, the note in `steam-tile.md` that an in-place update
needs no second `steam-install`, and the scattered environment variables collected
into one table in `development.md`.

The README keeps what belongs on a front page: what this is, the install line, the
two first commands, the status table, an index of the documentation, and how to
contribute. 72 lines.

## 2026-09-17 20:35 — Checked

Every relative link in every Markdown file in the repository resolves — the moved
ones needed `../` for their references into `RECORD/` and `.github/`. The two
cross-references the README used to make to its own anchors are gone with the
sections they pointed at, and `install.sh` pointed at "the README" for the GOG
credentials, which is now `docs/gog-login.md`.
